# External assets

Place real environment and vehicle 3DGS `.ply` files here; vehicle `.glb` / `.gltf` remains supported for display-only mesh workflows. Paths in scene YAML are relative to the YAML file, never the working directory. Asset lengths are meters after explicit coordinate scale. `tools/create_vehicle_3dgs_scene.py` generates a configured scene for the bundled real assets. Test assets are in `avm_sim_ws/src/avm_bringup/example_assets/`.
