# Synthetic fixtures

test_room.ply is a deterministic Gaussian test room, not a captured or trained factory scene.
vehicle.glb is a simple procedural meter-scale vehicle proxy. Both are generated by
avm_bringup.assets.generate_assets; no external/private assets are required.

Use assets/ for private replacements and edit scene.yaml paths. Do not train boards
into the PLY. Their checker texture and physical dimensions remain dynamic scene state.
