# 需求与参考视频分析

已完整提取并阅读根目录《项目需求.docx》的 3.1–3.5 与 4.1–4.5。文档包含场景管理、标定仿真、算法对接、分析和系统管理。当前实现以本次用户消息定义的 MVP 为范围，不实现 AI、自动标定、报告、用户权限、场景库和版本管理。

demo_example.mp4 共 1535 帧，14.325 fps，107.16 秒。使用 OpenCV 解码并检查覆盖全片的 24 个关键帧，抽帧脚本为 tools/inspect_inputs.py。

| 时间 | 可见内容 | 本原型对应 |
| --- | --- | --- |
| 0–25 秒 | 左上场景/点云概览，右上多路道路相机视图，底部配置区与表格 | 3D 视口与独立传感器预览 |
| 约 30 秒 | 打开场景选择下拉 | Load Scene / Gaussian PLY |
| 约 35 秒 | 车辆参数表出现第一行 | Add Vehicle 与对象选择 |
| 40–70 秒 | 行内数值、下拉选项变化，预览中车辆位置/朝向变化 | XYZ/RPY、Camera properties、异步图像更新 |
| 80–107 秒 | 增加多行车辆配置，多视图持续更新 | 对象增删和图像联动；本版限定一个标定车辆 |

关键帧未能确认参考视频存在 6DoF Gizmo 和标定板编辑，这两项依据用户明确要求实现。视频主要体现“编辑参数后多个预览同步反馈”的交互模式，本项目不宣称复制了其内部渲染算法。

原始需求中的 1080P/30FPS、99% 保真、72h 稳定性未被当作当前已达到指标。本轮无真实训练 PLY、GLB 和相机标定参数；示例 Gaussian、车辆、内外参均为可替换测试数据。
